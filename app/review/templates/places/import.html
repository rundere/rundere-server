The file

The first row names the columns, in any order: {% for c in columns %}{{ c }}{{ ", " if not loop.last }}{% endfor %}. Each row needs a name or a Maps url; the rest is optional.

  • url is a Google or Apple Maps place link. A short link (maps.app.goo.gl) can't be read from a file, so give such a row a name too.
  • lat and lon place the pin. Without them a place waits in Unsorted, under “Needs a pin”.
  • list puts the place in one of your lists, or makes the list. To put a place in two lists, repeat its row.
  • kind is restaurant, tour, lodging, event or note. priority is must or someday. country is a two-letter code, like GB.

Save it from your spreadsheet as “CSV UTF-8”. The file is read once and not kept.
