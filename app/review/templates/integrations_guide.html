How to connect AirTrail and AdventureLog

← Back to Connections

Before you start

  • Both are optional. Run·dere keeps your trips, timeline and flights with neither connected; a connection only logs your captures there as well.
  • Each connection is yours: your server address and your own token, so Run·dere can only do what your account there may do. Other people connect their own.
  • You set it up yourself, signed in to Run·dere on the web or in the app. Connected apps and AI agents (Claude, MCP clients, API tokens) can't add, change or read a connection.
  • The token is stored encrypted and never shown again — only its last four characters.
  • The server address must be public https. A server on your home network (e.g. http://airtrail:3000) works only if your Run·dere admin has allowed that host.

AirTrail

Needs AirTrail 3.13 or newer. Run·dere talks to it only through its API — no database access.

  1. In AirTrail, open Settings → Security and expand API Keys. Click Create.
  2. Name it Run·dere, so you can revoke just this one later.
  3. Choose a custom set of scopes — only these:
    ScopeWhy Run·dere needs it
    flight.read.ownsee your flights, so nothing is logged twice
    flight.create.ownlog a flight you captured
    flight.update.ownapply a changed booking
    flight.delete.ownremove a cancelled flight
    reference_data.readlook up an airline you haven't flown before
    profile.readcheck the key works
    No .any or administration scopes: Run·dere only ever writes flights you're on.
  4. Click Create key and copy it — AirTrail shows it once.
  5. In Run·dere, go to Connections → Connect AirTrail. Paste the key, and enter your AirTrail address (the one you open in the browser, e.g. https://airtrail.example.com).
  6. Save. Run·dere tests it straight away: it lists your flights and checks the airline lookup. "Connected" means you're done.

The AirTrail user id field can stay empty: flights are logged as the owner of the key. Only flights you're on go to AirTrail; a companion's booking never does.

AdventureLog

  1. In AdventureLog, open Settings → Integrations (API keys) and create a key named Run·dere. Copy it.
  2. In Run·dere, go to Connections → Connect AdventureLog. Paste the key and enter the address Run·dere should call.
  3. If you open AdventureLog in the browser at a different address than the one Run·dere calls (e.g. Run·dere uses an internal name), put the browser one in Browser address, so "View in AdventureLog" links work.
  4. Save. Run·dere lists your collections to test it.

With AdventureLog connected, captures are matched to your own collections, and a trip page gets Advanced → AdventureLog sync.

Changing or removing a connection

  • Test re-checks it any time. Turn off stops Run·dere sending anything, and keeps the key for later.
  • Changing the address needs the key again, so a saved key is never sent somewhere new.
  • Remove deletes the stored key. Delete the key in AirTrail or AdventureLog too if you don't need it any more.
  • Only captures processed after you connect go there. What you captured before stays in Run·dere (it's all on your trips); it isn't sent back in time.
